## 功能简介

生物样本量化器打开一个托管 Gradio 工作区，用于测量单张图像中分离的叶片、种子或谷粒。它检测前景组件，估算其几何形状和颜色，显示带标注的预览，并将测量结果导出为 CSV 和 JSON。

:::info 托管分析

分析在公共 `smiler488/image-quantifier` Hugging Face Space 中运行。嵌入式工作区在空闲后可能需要时间唤醒，所选图像会离开此静态网站进行服务端处理。

:::

## 开始之前

- 准备一张背景干净、照明均匀的清晰图像。
- 保持样本分离；相互触碰的对象可能被合并为一个组件。
- 如需以毫米为单位的测量，请在图像左上角放置一个参考物体，与样本在同一平面，并输入其测量尺寸。
- 将 **Expected count**（预期数量）设置在你希望返回的样本数量或以上。当前控件从 1 开始，默认为 5。
- 除非你已审查托管服务并愿意将其上传到 Hugging Face，否则请使用非敏感图像。

## 快速流程

1. 打开应用并等待 **Analysis workspace loaded**（分析工作区已加载）。如果 Space 正在唤醒，请等待并在必要时使用 **Retry**（重试）。
2. 在 **Upload image**（上传图像）中，选择一张本地图像。当托管 Gradio 界面和浏览器权限支持时，也可能出现摄像头选项。
3. 在 **Sample type**（样本类型）下选择 **leaves**（叶片）或 **seeds-grains**（种子-谷粒）。
4. 设置 **Expected count**（预期数量）、**Reference size (mm)**（参考尺寸，毫米）以及最小和最大组件面积。
5. 点击 **Analyze**（分析）。
6. 在接受结果之前检查 **Annotated**（标注图）和 **Metrics**（指标表）。
7. 如有需要，在 **Correction mode**（修正模式）下选择 **set-ref**（设置参考）或 **toggle-sample**（切换样本），然后在 **Annotated** 中点击相关对象。
8. 下载 **CSV export**（CSV 导出），并将原始图像和设置与结果一起保留。

## 控件与输出

| 控件                                 | 当前行为                                                                                  |
| ------------------------------------ | ----------------------------------------------------------------------------------------- |
| Upload image                         | 向托管分析流程提供一张图像。                                                               |
| Sample type                          | 在当前实现中改变结果排序。                                                                 |
| Expected count                       | 最多保留所请求数量的检测组件。                                                             |
| Reference mode                       | 显示 `auto`、`coin` 和 `square`；当前检测器对这三个标签使用相同的左上角候选搜索。         |
| Reference size (mm)                  | 将检测到的参考边界框尺寸从像素转换为毫米。                                                 |
| Min / Max area                       | 拒绝超出所选像素面积范围的连通组件。                                                       |
| Color tolerance / HSV H lower / upper | 为兼容性显示在界面中；当前前景检测器不将这些值应用于其掩码。                               |
| Correction mode: set-ref             | 将点击的检测组件用作参考并重新计算测量。                                                   |
| Correction mode: toggle-sample       | 包含或排除最近的检测组件并重新计算输出。                                                   |
| Analyze / Reset                      | 运行分析或清除生成的输出和修正状态。                                                       |

指标表和导出可包含：

- 样本标签和像素中心；
- 以参考推导的公制单位表示的长度、宽度、面积和周长；
- 长宽比、圆度和方向角；
- 平均 RGB 和 HSV 值；
- 简单的绿色和棕色颜色指数。

这些颜色指数是可见光摘要。它们不是 NDVI、叶绿素测量值或校准光谱仪器的替代品。

## 工作原理

托管流程将最长边超过 1024 像素的图像缩小。它在 LAB 颜色空间中从四个图像角估算背景颜色，应用 Otsu 阈值和形态学清理，然后测量剩余的连通组件。

检测器将一个合理的左上角组件视为参考，从其最大边界框维度派生比例，并使用基于 PCA 的轴计算组件长度、宽度和角度。预期数量设置随后截断排序后的组件列表。修正操作根据所选组件重新计算表格、标注图像、CSV 和 JSON。

## 数据、隐私与外部服务

- 在框架内输入的图像和设置由 Hugging Face 基础设施处理，而非 GitHub Pages 站点。
- 可用性、启动时间和摄像头选项取决于托管 Space 及其当前 Gradio 运行时。
- 外层页面检查公共 Space 状态，并在嵌入不便时提供 **Open separately**（单独打开）。
- 本页面不提供项目级账户或私有存储。请在关闭会话之前下载所需结果。

## 局限性

:::caution 测量有效性

绝对尺寸的可靠性仅取决于检测到的参考、其输入尺寸、图像透视、对焦和样本放置。如果未找到合适的参考，当前服务回退到标称比例；这些毫米值不得视为校准测量值。

:::

- 参考模式标签目前不会选择不同的特定形状检测器。
- 可见的颜色容差和 HSV 控件不会改变当前前景掩码。
- 背景相似性、阴影、高光、重叠或精细结构可导致组件遗漏或合并。
- 缩小到 1024 像素可能去除精细细节。
- 不保证准确性、可重复性或亚像素精度。在研究使用之前，请对照手工测量验证工作流。
- 工作区一次处理一张图像，不提供批量分析或持久项目存储。

## 排障

| 问题                    | 应检查什么                                                                            |
| ----------------------- | ------------------------------------------------------------------------------------- |
| 工作区保持空白          | 等待 Space 唤醒，选择 **Retry**，或使用 **Open separately**。                         |
| 返回的对象太少          | 增大 **Expected count**，放宽面积限制，分离触碰样本，改善背景对比度。                 |
| 样本被当作参考          | 选择 **set-ref** 并点击预期参考，然后查看重新计算的表格。                              |
| 测量了不需要的对象      | 选择 **toggle-sample** 并点击它以排除。                                               |
| 公制尺寸看起来不合理    | 确认参考被检测到，输入其实际尺寸，保持在样本平面，避免透视畸变。                      |
| 摄像头输入不可用        | 上传本地图像或单独打开 Space；嵌入式摄像头支持因浏览器和运行时而异。                  |
