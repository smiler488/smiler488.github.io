## 功能简介

AI 期刊选择器帮你决定稿件投到哪里。

- **第一次投稿或刚进入新领域：** 粘贴标题和摘要，选择器会找出近几年发表过与你的稿件最相似论文的期刊。
- **已有意向期刊：** 最多填写五个。每个期刊都按与推荐期刊相同的标准打分，并列出它发表过的相似论文，方便你判断稿件是否合适。

每个推荐期刊都有真实论文作为依据，所有数据都取自检索当时的 OpenAlex 或 DOAJ。AI 模型是可选的。选用模型后，还会：
- 生成英文检索词（中文摘要需要）；
- 逐刊评估契合度；
- 把推荐期刊分为冲刺、最佳匹配、稳妥三档；
- 对每个意向期刊给出判断和投稿信要点。

## 期刊是怎样找出来的

1. **检索词：** 从标题和摘要中提取关键短语，你填写的关键词优先；选用模型时由模型生成。
2. **相似论文：** OpenAlex 返回所选时间范围内标题和摘要与检索词最匹配的 200 篇期刊论文。
3. **与摘要比对：** 用 TF-IDF 余弦相似度把每篇论文与你的标题和摘要逐一比对。
4. **期刊得分：** 取与稿件最相似的 100 篇论文，把每个期刊在其中的论文相似度相加，作为该刊得分。**匹配度**是该得分相对最佳期刊的比例，卡片上列出了支撑这一得分的论文。
5. **期刊数据：** 来自 OpenAlex，开放获取期刊再由 DOAJ 补充细节。

这一思路与 JANE（Schuemie & Kors, 2008）相同：发表过与你的稿件相似论文的期刊，就是好的候选。

:::info 验证
测试选取了六个领域核心期刊的 24 篇近期论文，涵盖农业与生物学、生物化学、计算机科学、环境科学、材料科学和医学。每篇论文的标题和摘要都走完整个流程，并在结果中排除论文本身。
- 论文实际发表的期刊有 5 次排在第一、9 次进入前十。
- 若该刊在检索期内发表过相关研究，12 次中有 9 次进入前十。

多数稿件都有好几个合适的期刊，所以列表中的其他期刊通常是合理的备选，而不是错误。测试脚本和结果在网站代码库中（`scripts/journal-benchmark.mjs`、`scripts/benchmarks/`）。
:::

## 开始之前

- 准备好标题和摘要。OpenAlex 收录的是英文标题和摘要，所以英文效果最好；中文摘要请补充英文关键词，或选用模型。
- 检索不需要账号或密钥。匿名使用 OpenAlex 时，每个网络每天约可检索 100 次；同一标签页里重复的检索不计次数。
- 模型是可选的。如需使用，选择服务商和模型，并填写你自己的 API 密钥，参见[模型服务商](#模型服务商)。

## 快速流程

1. [打开 AI 期刊选择器](/app/journal-selector)。
2. **01 · 模型：** 只检索期刊就保持“本地演示”；需要文字评估时选择服务商、模型并填写 API 密钥。
3. **02 · 稿件：** 填写**标题**、**摘要**，以及可选的**关键词**（用分号分隔）。
4. **03 · 目标：**
   - 在**已有意向的期刊**中最多填写五个期刊，每行一个，填刊名或 ISSN。
   - 设置开放获取要求、版面费上限、出版国家、审稿速度、时间范围和推荐数量。
5. **04 · 评价指标** 列出每项数据的来源。
6. **05 · 检索：** 点击**查找期刊**。
7. 查看结果：
   - **期刊是怎样找到的**，可在此修改检索词后点击**重新检索**；
   - **投稿策略**（选用模型时）；
   - **你的目标期刊**；
   - **推荐期刊**和对比表。
8. 点击**下载 CSV** 保存候选清单。参数记录会写明设置、检索词和数据来源。

## 结果怎么看

| 项目 | 含义 |
| --- | --- |
| **匹配度** | 该刊论文与你的稿件的相似度之和，相对最佳期刊的比例。发表相关论文很多的大刊可达 100%；专业性强的期刊排名可能靠后，但同样是很好的选择。 |
| **相似论文** | 该刊在与你的稿件最相似的 100 篇论文中占几篇。展开**该刊发表的相似论文**即可阅读；这些论文也值得引用，并可在投稿信中提及。 |
| **高度 / 中等 / 较弱匹配**（目标期刊） | 高度：位列检出期刊前五，或匹配度不低于 40% 且有两篇以上相似论文；中等：位列前 15，或匹配度不低于 15%；较弱：至少有一篇相似论文。 |
| **两年篇均被引** | OpenAlex 的两年篇均被引：每篇论文在两年内的平均被引次数，计算方式与影响因子相同，但基于 OpenAlex 数据，并非科睿唯安的影响因子。 |
| **H 指数**、**年发文量** | 来自 OpenAlex。发文量反映该刊每年处理的稿件规模。 |
| **版面费** | 开放获取期刊取 DOAJ 申报的费用，其他期刊取 OpenAlex 标价；订阅期刊的这一费用是可选的开放获取费。 |
| **投稿至出版周数**、**同行评审** | 来自期刊向 DOAJ 的申报，仅限开放获取期刊。超过你期望的审稿速度时会出现提示标签。 |
| **核对** | 期刊主页（作者须知）、SCImago、NLM 目录、JCR、中科院分区和 DOAJ。 |

影响因子、JCR 分区、中科院分区、CiteScore 和录用率属于商业数据或未公开数据，在 CSV 中保留为空列，供你核对后填写。

## 选用 AI 模型时

模型收到的是你的稿件、偏好和检出期刊的数据，并且只评价这些期刊：
- **投稿策略：**
  - 冲刺（契合且被引更高）；
  - 最佳匹配（收稿范围最贴近）；
  - 稳妥（契合度好、收稿范围更宽）；
  - 另附投稿准备清单。
- **逐刊评估：** 稿件与收稿范围的契合点、应突出的内容和需要注意的问题。
- **意向期刊：** 给出判断（可以投稿、建议先加强契合点或建议重新考虑），附理由、投稿信要点，以及列表中的备选期刊。

系统要求模型不得给出数据中没有的指标。模型的文字仅供参考，不代表录用结果；中文站点上模型会用中文回答。

### 模型服务商

服务商列表涵盖：
- OpenAI、Anthropic、Google Gemini、xAI、Mistral、Meta；
- DeepSeek、通义千问、Kimi、智谱 GLM、MiniMax、豆包、混元、文心、阶跃星辰、小米 MiMo；
- OpenRouter、硅基流动、Groq、Together AI、Hugging Face 等聚合平台；
- 本机运行的 Ollama 或 LM Studio；
- 任何兼容 OpenAI 或 Anthropic 格式的接口。

## 数据、隐私与外部服务

- **OpenAlex** 只收到检索词，不会收到摘要；**DOAJ** 只收到 ISSN。
- 选用模型时，标题、摘要、偏好、补充说明和期刊数据会发送到 **01 · 模型** 中显示的接口。未接受服务商数据政策前，请勿发送保密稿件。
- API 密钥只保存在标签页内存中，刷新、切换服务商或离开页面时清除。
- 检索结果只缓存在当前标签页会话中。

## 局限

- 只能找到在所选时间范围内发表过相关论文的期刊。新创刊或刚涉足该主题的期刊可能被漏掉，可放宽时间范围，或把它填为意向期刊。
- 部分出版社的论文在 OpenAlex 中缺少摘要，这些期刊只能按标题匹配。
- “中国出版”按出版机构所在国判断。CSCD、北大核心等收录情况没有开放数据，需要另行核对。
- 数据反映检索当时 OpenAlex 和 DOAJ 的记录，可能比期刊官网更新得慢。

## 常见问题

- **提示“OpenAlex 免费额度已用完”：** 等每日额度恢复；已显示的结果仍保留在标签页中。
- **推荐的期刊不相关：** 在**检索词**中删去过于宽泛的词（例如单个常用词）后点击**重新检索**，或补充更精确的关键词。
- **意向期刊显示“OpenAlex 中未找到”：** 改填 ISSN。
- **中文摘要检索不到结果：** 补充英文关键词，或选用模型。
- **模型返回 401、403、404 或 429：** 检查服务商、模型 ID、密钥权限和额度。期刊检索本身在“本地演示”下仍可正常使用。
