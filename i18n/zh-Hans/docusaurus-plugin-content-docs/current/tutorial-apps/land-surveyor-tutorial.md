## 功能简介

土地测量器从手动输入或浏览器地理定位捕获的坐标构建有序田块边界。添加三个或更多顶点后，它闭合多边形并以平方米、公顷和亩为单位估算水平面积。

:::info 估算，非地籍测量
本应用用于快速田块筛选。它不替代投影 GIS 工作流、校准的 GNSS 接收机或具有法律效力的边界测量。
:::

## 开始之前

- 计划按顺时针或逆时针顺序依次添加边界顶点。
- 手动输入时，使用 WGS84 风格的十进制纬度和经度。
- 设备定位时，使用 HTTPS 并在提示时允许地理定位。
- 在弯道周围捕获更多顶点，但避免重复点和自相交路径。

## 快速流程

1. 可选选择 **Check location access**（检查定位访问）以查看权限可用性而不添加点。
2. 输入 **Latitude (Lat)**（纬度）和 **Longitude (Lng)**（经度），然后选择 **Add Point**（添加点）；或选择 **Add current location**（添加当前位置）。
3. 沿田块边界依次继续。
4. 查看 **Live polyline preview**（实时折线预览），从 **Coordinate list**（坐标列表）中删除任何错误顶点。
5. 至少有三个点时，选择 **Close Polygon**（闭合多边形）。
6. 读取面积估算或选择 **Reset**（重置）重新开始。

## 控件与输出

| 控件或面板                             | 实际行为                                                                                  |
| -------------------------------------- | ----------------------------------------------------------------------------------------- |
| **Check location access**              | 报告浏览器地理定位是否已授权、可提示或被阻止。它不添加点。                                |
| **Latitude (Lat)** / **Longitude (Lng)** | 接受 `-90…90` 和 `-180…180` 范围内的十进制值。                                            |
| **Add Point**                          | 追加一个手动坐标并重新打开之前闭合的多边形。                                              |
| **Add current location**               | 请求新的高精度浏览器定位，并将报告的精度存储在点来源标签中。                              |
| **Close Polygon**                      | 当至少存在三个点时启用填充预览和面积计算。                                                 |
| **Delete**                             | 移除一个顶点；再次闭合多边形以更新结果。                                                   |
| **Reset**                              | 清除点、输入、计算和消息。                                                                 |
| **Area estimate**                      | 显示 `m²`、公顷（`m² / 10,000`）和亩（`m² / 666.6667`）。                                 |

## 工作原理

计算器以各顶点的平均位置为中心，在 WGS 84 椭球上把顶点投影为米制坐标（在平均纬度处，南北方向用子午圈曲率半径，东西方向用卯酉圈曲率半径），再用鞋带公式计算面积。已用 GeographicLib 的测地线面积验证，20 m 至 2 km 的多边形误差在 0.05% 以内（通常优于 0.01%）。周长在同一投影上计算。

闭合多边形时，工具会自动检查：若边相互交叉，会指出相交的边并拒绝计算面积（自相交多边形的面积是错误的）；与前一个点相距不足 5 cm 的顶点会被标出，通常是重复点击。

SVG 预览在两个方向上使用相同的米制比例、上方为北，因此轮廓保持真实形状。预览没有底图。

## 数据、隐私与外部服务

手动坐标、设备定位和结果保留在当前浏览器标签页中。没有服务器计算、地图提供商或自动上传。浏览器地理定位是唯一使用的受保护功能。

闭合后的边界可以保存到本地工作区，下载为 GeoJSON 或 KML（属性中包含面积、周长和计算方法），也可以按中心点直接跳转到气象工具。

## 局限性

:::caution 精度边界

- 局部投影适用于数千米以内的田块；面积很大、靠近极地或跨越日期变更线的多边形需要完整的测地线方法。
- 不支持带孔洞或由多个部分组成的多边形。
- 浏览器报告的 GPS 精度可能远大于坐标显示精度。
- 结果表示水平平面估算，非地形表面积。
- 不要将结果用作法律、地籍、施工或土地交易测量。
  :::

## 排障

| 问题                             | 应检查什么                                                                                         |
| -------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Add current location** 不可用  | 使用手动输入或在浏览器和操作系统中启用地理定位支持和权限。                                          |
| 坐标被拒绝                       | 确认两个值都是显示纬度和经度范围内的十进制数。                                                     |
| 未显示面积                       | 至少添加三个点并选择 **Close Polygon**。                                                           |
| 形状看起来被拉伸                 | 预览独立适应纬度和经度；使用坐标列表和面积结果，而非将其视为地图。                                  |
| 面积不合理                       | 检查点顺序、重复点、意外异常值和设备定位精度。                                                     |
