## 功能简介

灌溉布局设计器是一个用于矩形滴灌区块的交互式筛选工作区。它绘制按比例的 SVG 示意图，并估算同时流量、主管和支管流速、Hazen–Williams 水头损失、压力裕度和一个基于压力变化的简单均匀度指标。

:::caution 仅供初步设计
计算器简化了滴头行为、毛管损失、管件、瞬变和地形。请通过现场测量、厂家数据和合格的灌溉工程师确认最终布局。
:::

## 开始之前

- 测量区块长度、宽度、行方向和代表性坡度。
- 收集水泵压力和流量额定值、过滤器损失、管径和滴头规格。
- 确定方案是假设环形主管、双侧供水支管还是压力补偿滴头。
- 将所有显示值视为一个对比方案，而非施工规格。

## 快速流程

1. 在 **Field & Terrain**（田块与地形）中，输入尺寸、方向和坡度。
2. 在 **Headworks & Constraints**（首部与约束）中，设置水泵压力、最大流量、过滤器损失、施肥、允许压力变化和最大流速。
3. 配置 **Mainline**（主管）、**Submains**（支管）和 **Drip laterals**（滴灌毛管）。
4. 随数值更新查看 **Layout preview**（布局预览）、**Hydraulic summary**（水力摘要）和 **Constraint checks**（约束检查）。
5. 选择 **Export SVG**（导出 SVG）以保存当前示意图。
6. 选择 **Reset**（重置）或 **Reset defaults**（重置默认值）以恢复初始方案。

## 控件与输出

| 分组                         | 输入或输出                                                                                                       |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Field & Terrain**          | 长度、宽度、从北顺时针方向、纵向坡度和横向坡度。                                                                 |
| **Headworks & Constraints**  | 水泵压力、水泵流量额定值、过滤器损失、固定 5 kPa 施肥损失开关、允许 `ΔP` 和流速限制。                             |
| **Mainline**                 | 直径、水力长度、PE（`C≈140`）或 PVC（`C≈150`）、边缘或中心线显示，以及环形/双端供水。                             |
| **Submains**                 | 间距、直径、双侧供水和 `Valve every (runs)`（每若干行一个阀门）规划值。                                           |
| **Drip laterals**            | 毛管间距、滴头间距、滴头流量、工作压力、毛管长度和压力补偿标签。                                                   |
| **Layout preview**           | 包含首部、主管、支管和毛管的按比例 SVG 示意图。                                                                   |
| **Hydraulic summary**        | 毛管总数、系统流量、主/支管流速和水头损失、可用压力、水泵压力和估算 CU。                                           |
| **Constraint checks**        | 主管流速、水泵流量、主管后非正压、毛管负压力裕度和较大坡度水头差的警告。                                           |

`Valve every (runs)` 和压力补偿开关记录在方案中，但当前不会改变几何或水力方程。

## 工作原理

### 布局与需求

- 支管和毛管数量通过向下取整的间距规则推导，且至少一行。
- 每条毛管的滴头数根据配置的毛管长度和滴头间距估算。
- 系统流量假设每条推导出的毛管同时运行，每个滴头供应输入的标称流量。
- 方向旋转局部 SVG 几何；它不会对图纸进行地理配准。

### 水力估算

主管和支管摩擦使用：

```text
hf = 10.67 × L × Q^1.852 / (C^1.852 × d^4.87)
v  = Q / (π × d² / 4)
```

主管使用所选材料系数。支管使用 `C=140`。环形供水将有效主管长度和流量减半；双侧供水将有效支管长度和流量减半。

可用毛管压力从水泵压力中减去过滤器损失、可选的 5 kPa 施肥损失、主管损失、支管损失和正向纵向坡度水头。横向坡度作为警告报告，但不从显示的可用压力中扣除。

显示的 CU 是一个有界启发式值：

```text
estimated CU = clamp(100 − 1.6 × allowable ΔP, 60, 98)
```

它不是根据模拟滴头流量测量计算的。

## 数据、隐私与外部服务

所有输入、计算和 SVG 生成均在浏览器本地运行。应用不上传设计或调用水力服务。设置仅保留在当前页面会话中，除非导出了 SVG。

## 局限性

- 毛管摩擦、局部管件、阀门、过滤器曲线、高程剖面、压力瞬变和水锤未建模。
- 标称滴头流量不通过压力–流量曲线调整。
- 横向坡度、阀门频率和压力补偿开关不会改变压力计算。
- 仅将主管流速与输入的流速限制进行比较。
- 毛管长度影响需求和纵向坡度，而示意图中的毛管跨越显示的田块区块。
- SVG 没有地理坐标，不应视为 CAD、GIS 或安装图纸。

## 排障

| 问题                         | 应检查什么                                                                        |
| ---------------------------- | --------------------------------------------------------------------------------- |
| 系统流量超过水泵额定值       | 减少同时运行的毛管或滴头流量，或评估分区和不同水泵方案。                          |
| 压力裕度为负                 | 增大可用压力，减少损失，增大管径，缩短管线或比较环形/双侧供水。                    |
| 出现主管流速警告             | 增大主管直径或减少同时流量。                                                      |
| CU 值看起来异常              | 它仅由 **Allowable ΔP (%)** 推导，不是管网模拟。                                  |
| 旋转后图纸被裁剪             | 尝试较小的方向角进行检查；导出使用相同的固定 SVG 画布。                            |
| SVG 无法下载                 | 允许浏览器下载并再次尝试 **Export SVG**。                                          |
