## 功能简介

灌溉布局设计器用于校核矩形滴灌小区的水力设计。它按比例绘制布局图，并针对最不利轮灌组中最远的灌水小区计算：干管、支管和滴灌带（毛管）的沿程水头损失，地形高差的影响，支管入口的可用压力与灌水小区所需压力的对比，小区内的压力偏差，以及由此产生的灌水器流量偏差。流速、水泵流量、压力不足和偏差过大时会给出警示。

## 准备工作

- 测量小区的长、宽，以及顺行方向和垂直行方向的坡度。
- 收集水泵扬程和额定流量、过滤器损失和各级管道管径。
- 从滴灌带产品说明书中查取灌水器流量、滴头间距、工作压力和管道内径，并确认是否为压力补偿式滴头。

## 快速流程

1. 在 **Field & Terrain** 中输入尺寸、方向和坡度。
2. 在 **Headworks & Constraints** 中设置水泵压力和流量、过滤器损失、施肥装置、允许压力偏差和最大流速。
3. 配置 **Mainline**、**Submains**（间距、管径、每个轮灌组同时开启的支管数）和 **Drip laterals**。
4. 查看 **Hydraulic summary** 和 **Constraint checks**，调整支管间距、管径或轮灌分组，直到没有警示。
5. 点击 **Export SVG** 保存布局图；导出记录中包含设计参数和主要计算结果。

## 布局

采用大田作物膜下滴灌的常用布局：**干管**沿田块长度方向布置（位于一侧边缘或中线），**支管**垂直于干管、横跨田宽，沿田长等间距排列，**滴灌带**沿作物行铺设在每条支管两侧，每侧长度为支管间距的一半。支管条数等于田长除以间距后取整，毛管长度为实际间距的一半。干管布置在中线时，从支管中部供水，支管的单侧长度减半。

## 计算方法

- **毛管：** Darcy–Weisbach 公式，摩阻系数采用 Blasius 公式 `f = 0.316 · Re^−0.25`（Re < 2000 时取层流 `64/Re`），再乘以等间距出流的 Christiansen 多口系数。
- **支管和干管：** Hazen–Williams 公式 `hf = 10.67 · L · Q^1.852 / (C^1.852 · d^4.87)`，PE 管 C 取 140，PVC 管取 150；支管按毛管出口乘以 Christiansen 多口系数。干管按设定的同时开启支管数校核最远支管，环状（两端）供水时干管长度和流量各减半。
- **Christiansen 多口系数：** `F = 1/(m+1) + 1/(2N) + √(m−1)/(6N²)`，m 取 1.75（Blasius）或 1.852（Hazen–Williams）。
- **灌水小区入口所需压力**（Keller & Karmeli）：`h = h_a + 0.75 · Δh_f + 0.5 · Δz`，h_a 为灌水器工作压力。
- **最远支管入口的可用压力：** 水泵压力减去过滤器损失、施肥装置损失（启用时 5 kPa）、干管沿程损失和干管沿线的高差。
- **小区内压力偏差：** （支管与毛管沿程损失 + 小区内高差）÷ 工作水头。
- **灌水器流量偏差：** `q_var = 1 − (1 − h_var)^x`，非压力补偿紊流滴头 x 取 0.5，压力补偿滴头在调压范围内 x 约为 0。流量偏差 10% 以内为良好，20% 以内为可接受。

**验证：** 网站测试套件用 Christiansen 原始表值检验多口系数，用"流量逐段递减的分段累加摩阻"检验多口系数法得到的毛管和支管损失（误差在 2% 以内），并用手算值检验 Hazen–Williams 公式。

## 数据与隐私

所有输入、计算和 SVG 生成都在浏览器本地完成，设计数据不会上传。

## 局限

- 未计入管件、阀门和接头的局部损失、过滤器性能曲线、瞬变流和水锤。
- 流量偏差未计入灌水器的制造偏差。
- 假设每个灌水小区坡度均匀；地形起伏复杂时需要完整的管网分析。
- SVG 是按比例绘制的示意图，不含地理坐标。

## 常见问题

| 问题 | 检查内容 |
| --- | --- |
| 单个轮灌组流量超过水泵额定流量 | 减少每组同时开启的支管数，或选用流量更小的滴头。 |
| 压力不足 | 提高水泵压力、加大干管管径或降低过滤器损失。 |
| 压力偏差过大 | 缩短毛管（减小支管间距）、加大支管管径，或改用压力补偿滴头。 |
| 流速警示 | 加大该管段管径或减小其输水流量。 |
| SVG 无法下载 | 允许浏览器下载后重新点击 **Export SVG**。 |
