## 概述

![PhenoHUB 界面](/img/phenohub.png)

田间表型测量往往远离实验室电脑，而许多日常测量只需要一部手机：一片叶的倾角、一块地的面积、测点的天气、一次快速的图像分析、对一份数据表的初步查看。**PhenoHUB** 把这些工具整合进一个面向植物表型与光合研究的微信小程序。它在 iOS 和 Android 的微信中运行，无需安装，并连接 Python 后端，承担手机端难以完成的分析。

## 功能模块

### 表型测量

- **叶倾角。** 手机陀螺仪和加速度计实时给出手机姿态。将手机贴合叶片放置，读数即为叶片倾角；读数按叶片逐条记录，可依次测量一株植物的多片叶。
- **地块面积。** 沿地块边界行走记录 GPS 轨迹，计算围合多边形的面积，并在平方米、公顷和亩之间换算。
- **图像定量分析。** 基于 OpenCV 处理植株图像，提取叶面积和颜色性状，支持多张图像批量处理。

### 环境信息

- **农业气象。** 获取测点所在位置的天气：温度、湿度和光照条件（来自气象服务），以及农业气象指标。
- **位置服务。** 基于 GPS/北斗定位获取坐标和海拔，并支持坐标转换。

### AI 辅助分析

- **AI 绘图智能体。** 将 CSV 文件生成为八类论文风格图表：带方差分析的柱状图、热图、折线图、直方图、小提琴图、散点图和雷达图，绘图前对输入数据进行检查。
- **AI 学术助手。** 辅助实验设计、分析方法选择和论文写作。

### 数据管理

支持 CSV 与 Excel 导入、数据清洗、描述统计、假设检验和回归分析，以及结果导出。

## 技术架构

| 层次 | 技术 |
|---|---|
| 客户端 | 微信小程序原生开发、TDesign Miniprogram 1.8.6、LESS |
| 图表 | Canvas API 绘制轻量图表，ECharts for Weixin 1.0.2 绘制交互图表 |
| 后端 | Python FastAPI，负责图像分析、统计和模型调用 |

轻量交互和传感器读数在手机端完成；图像分析、统计与 AI 功能在后端运行。项目按工具组织：

```text
PhenoHUB/
├── pages/
│   ├── hub/                         # 工具箱首页
│   ├── leafAngle/                   # 叶倾角
│   ├── landArea/                    # 地块面积
│   ├── agriWeather/                 # 农业气象
│   ├── imageQuantitativeAnalysis/   # 图像分析
│   ├── aiImage/                     # AI 绘图智能体
│   ├── aiJournal/                   # AI 学术助手
│   └── my/                          # 个人中心
├── components/
├── utils/
└── Backend code/                    # FastAPI 服务
```

## 应用场景

- 作物株型田间调查中的叶倾角与地块面积测量；
- 在表型测量的同时记录测点天气；
- 在田间或温室对试验数据做初步的图像与统计分析；
- 移动表型方法的教学。

## 适用范围与局限

手机传感器不是测绘或实验室仪器。叶倾角读数取决于手机与叶片的贴合方式；消费级 GPS 存在米级误差，因此面积测量适用于地块和田块，而不适用于小样方。气象数值来自服务商的站点或格点，而非植株处的传感器。基于颜色的图像性状在未经参考测量标定时为相对值。发送到后端和 AI 模型的数据会离开手机，敏感数据需相应处理。
