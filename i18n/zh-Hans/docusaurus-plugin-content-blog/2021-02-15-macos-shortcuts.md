## 速览

这里整理了科研和开发中最常用的快捷键：查找文件、编辑文本、管理窗口、截屏留档，以及在应用卡死时恢复。

- 不同应用和键盘布局下，快捷键可能略有不同。
- 在较新的键盘上，按 **Fn/地球仪** 键可能会打开字符检视器。
- 恢复类快捷键可能导致未保存的内容丢失，使用前请看相应提示。

## 修饰键符号

| 符号        | 按键              |
| ----------- | ----------------- |
| `⌘`         | Command           |
| `⌥`         | Option / Alt      |
| `⌃`         | Control           |
| `⇧`         | Shift             |
| `Fn` / `🌐` | Function / Globe  |

## 搜索、应用与窗口

- `⌘ Space` —— 打开 Spotlight。
- `⌘ Tab` —— 切换应用；按住 Command 再连按 Tab 可继续选择。
- `⌘ H` —— 隐藏前台应用的所有窗口。
- `⌥ ⌘ H` —— 隐藏其他所有应用的窗口。
- `⌘ M` —— 最小化当前窗口。
- `⌘ W` —— 关闭当前窗口或标签页。
- `⌘ Q` —— 退出当前应用。
- `⌃ ⌘ Q` —— 锁定屏幕。

## 截屏与录屏

- `⇧ ⌘ 3` —— 截取整个屏幕。
- `⇧ ⌘ 4` —— 截取选定区域；按下后再按空格键可截取单个窗口。
- `⇧ ⌘ 5` —— 打开截屏与录屏控制面板。

在截屏快捷键中同时按住 `⌃`，截图会复制到剪贴板，而不是保存为文件。

## 访达

### 文件

- `⌘ Delete` —— 把所选项目移到废纸篓。
- `⇧ ⌘ Delete` —— 清倒废纸篓（会先弹出确认）。
- `⌘ I` —— 显示所选项目的信息。
- `⌘ D` —— 制作所选项目的副本。
- `Space` —— 用快速预览查看所选项目。

### 导航

- `⌘ ↑` —— 回到上一级文件夹。
- `⌘ ↓` —— 打开所选项目。
- `⇧ ⌘ G` —— 输入路径前往文件夹。
- `⌘ 1`、`⌘ 2`、`⌘ 3`、`⌘ 4` —— 在图标、列表、分栏和画廊视图之间切换。

## 文本编辑与导航

以下快捷键适用于大多数系统文本框和常见编辑器：

- `⌘ A` —— 全选。
- `⌘ C`、`⌘ X`、`⌘ V` —— 复制、剪切和粘贴。
- `⌘ Z` —— 撤销。
- `⇧ ⌘ Z` —— 重做（大多数应用）。
- `⌥ ←` / `⌥ →` —— 光标左移或右移一个单词。
- `⌘ ←` / `⌘ →` —— 光标移到行首或行尾。
- `Fn Delete` —— 删除光标右侧的字符（无独立删除键的键盘）。

## Safari 与 Chrome

- `⌘ T` —— 打开新标签页。
- `⌘ W` —— 关闭当前标签页。
- `⇧ ⌘ T` —— 重新打开最近关闭的标签页。
- `⌘ L` —— 定位到地址栏。
- `⌘ R` —— 重新载入页面。
- `⌘ [` / `⌘ ]` —— 后退或前进。

部分快捷键可能被浏览器扩展或网页应用占用。

## 恢复与电源控制

:::warning 先保存工作
以下操作可能强制关闭应用，未保存的内容会丢失。只在应用菜单或苹果菜单都无法操作时使用。
:::

- `⌥ ⌘ Esc` —— 打开“强制退出应用程序”窗口。
- 长按电源键 —— Mac 完全无响应时强制关机。
- `⌃ ⌘ 电源键` —— 强制重启，不提示保存文档（适用于不带触控 ID 的内建键盘）。
- `⌃ ⌥ ⌘ 电源键` —— 退出所有应用后关机，有未保存文档的应用会先提示（适用于不带触控 ID 的内建键盘）。

电源键的行为因键盘类型（是否带触控 ID、是否外接）和 macOS 版本而不同。只要系统还能响应，优先通过 **苹果菜单 → 关机** 或 **重新启动** 操作。
