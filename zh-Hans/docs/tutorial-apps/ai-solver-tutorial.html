多模态 AI 解题器

通过屏幕截取、拍照或文字回答实验室安全考试题和其他问题：结构化答案、二次作答核对，并可自测所选模型。

  • 实验室安全考试
  • 答案核对
  • 相机 / 截屏
打开工具

功能简介​

多模态 AI 解题器把题目发给你选择的 AI 模型并显示答案。题目可以来自：

  • 屏幕上框选的区域；
  • 相机拍摄的照片；
  • 输入的文字。

它的主要用途是实验室安全考试。默认选中的实验室安全考试预设：

  1. 以醒目的字母或“正确/错误”给出答案；
  2. 显示题型、模型的把握程度、模型读到的题目、理由和依据的安全规范；
  3. 用第二次独立作答核对每个答案。

另有 18 个预设覆盖通用分析、数学、实验室隐患排查、植物识别、代码、翻译等领域，自定义模式可使用你自己的指令。

哪些经过核验，哪些没有

网站核验的是答案之外的各个环节：

  • 屏幕和相机截取；
  • 各服务商的请求格式；
  • 从模型回复中读出答案；
  • 两次作答的比对。

这些环节有自动化测试，并用参考模型完整跑通过。答案本身来自你选择的模型。 依赖某个模型之前，请先运行自测（32 道答案明确的实验室安全题）了解它的准确率；两次作答不一致的题目，请自行判断。

开始之前​

  • 在解题模型中选择服务商和模型，并填写你自己的 API 密钥。截屏和拍照题需要标注为“图像 + 文本”的模型。
  • 服务商列表涵盖：
    • OpenAI、Anthropic、Google Gemini、xAI、Mistral、Meta；
    • DeepSeek、通义千问、Kimi、智谱 GLM、MiniMax、豆包、混元、文心、阶跃星辰、小米 MiMo；
    • OpenRouter、硅基流动、Groq、Together AI、Hugging Face 等聚合平台；
    • 本机的 Ollama 或 LM Studio；
    • 任何兼容 OpenAI 或 Anthropic 格式的接口。
  • 屏幕截取需要桌面浏览器（Chrome、Edge、Firefox 或 Safari），并需你允许共享窗口。手机上通常不可用，请改用相机。
  • 本地演示只显示带标注的示例答案，不发送任何数据，也不会读题。

实验室安全考试：快速流程​

  1. 打开多模态 AI 解题器。提示词预设显示为实验室安全考试；页面会记住你的选择。
  2. 在解题模型中选择服务商、“图像 + 文本”模型，并填写 API 密钥。
  3. 可选，建议每个模型做一次：点击开始自测，查看得分和答错的题目。
  4. 在另一个窗口打开考试页面。在解题器中选择屏幕，点击截取屏幕，共享考试窗口，把框拖到题目和选项上，点击分析选区。
  5. 查看答案。按钮下方会显示一行简要答案（例如“答案：B · 两次作答一致”），回答区显示完整卡片。
  6. 下一题：在考试窗口翻到该题，点击截取并作答。共享保持开启，每次截取同一区域，每道题只需点一下。题目位置变了就点调整区域，答完后点停止共享。

在文本模式下也一样：粘贴题目和选项，点击提问。

答案怎么看​

项目含义
醒目的答案选项字母（单选一个、多选多个）、“正确/错误”，或填空、简答的文字。
题型 · 把握题目类型和模型自评的把握程度（较大、一般、较小）。
第二次独立作答结果一致第二次请求先逐项判断选项再作答，得出了相同答案。
第二次作答结果不同（…）两次作答不一致，说明题目有歧义或模型没把握。请重新读题，自行判断。
模型读到的题目模型从截图中读到的内容。若与屏幕上的题目不符，请调整区域。
理由、依据模型的解释和所依据的安全规范。
完整回复模型的原始回复，供核对。

自测​

开始自测会把 32 道答案明确的实验室安全题（单选 20 道、多选 4 道、判断 8 道）逐题发给所选模型，不做二次核对，然后报告答对多少题，并列出每道答错的题目、标准答案和模型答案。每道题向服务商发送一次请求，一次自测共 32 次请求。

题目涵盖浓酸稀释、金属火灾、电气火灾、化学灼伤和眼部接触、通风橱、易燃品存放、气瓶、汞洒落、废液、离心机、触电、生物安全柜、感染性废物、剧毒化学品、灭火器、逃生、个人防护和高压灭菌锅。在这套题上得分低于约 90% 的模型，考试中不宜单独依赖。

控件与输出​

控件作用
相机 / 屏幕 / 文本选择输入方式。
开启相机、拍照并解答开启相机并发送一张照片，长边最多 1,280 px。
截取屏幕请求共享屏幕或窗口，截取画面后放置选框。
分析选区发送选中区域（常见题目尺寸用 PNG，小字也清晰）。
截取并作答、调整区域、停止共享共享期间一键截取同一区域；移动区域；结束共享。
提问发送输入的文字。
提示词预设实验室安全考试、其他 18 个预设或自定义模式。文本模式现在也会应用预设。
二次作答核对实验室安全考试默认开启；关闭后请求次数减半。
开始自测用题库测量所选模型。

数据、隐私与外部服务​

  • 相机画面和屏幕内容在你发送题目之前都留在本机；只有选中的区域或照片以及提示词会发送到解题模型中显示的接口。
  • API 密钥只保存在标签页内存中，刷新、切换服务商或离开页面时清除。
  • 请勿截取密码、私人消息或其他你无权发送给服务商的内容。
你的责任

请遵守所参加考试的规定。各单位的安全规范不尽相同；模型答案与本单位培训材料不一致时，以培训材料为准。

局限​

  • 答案取决于模型；自测只是用一套题测量一个模型，不能覆盖所有题目。
  • 题目跨两屏，或一张图里有多道题时，只回答第一道完整的题。
  • 没有历史记录和导出功能。

常见问题​

  • “模型读到的题目”有误或不完整： 点击调整区域，框住完整题目和所有选项。
  • 两次作答经常不一致： 换用更强的模型，或参考自测得分。
  • 模型不接受图片： 选择标注“图像 + 文本”的模型，或改为输入文字。
  • 无法截取屏幕： 使用桌面浏览器并允许共享屏幕；手机上请用相机。
  • 401、403、404 或 429： 检查服务商、密钥、模型 ID、权限和额度。
  • 无法连接服务商： 该服务商不允许浏览器直连，请换用其他服务商或使用自己的代理。
