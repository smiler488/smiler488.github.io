标定靶生成器

生成可打印的棋盘格和编码圆形标定靶，支持实时尺寸预览、验证和 PDF 导出。

  • 实时预览
  • 打印比例
  • PDF 导出
打开工具 ↗

功能简介​

标定靶生成器为两类靶标创建页面内 SVG 预览和可打印 PDF：OpenCV 风格棋盘格和面向 Agisoft 工作流的编码分段圆形标记网格。输入使用物理毫米单位，并包含适配和范围验证。

打印比例是标定的一部分

始终以 100% / 实际尺寸 打印导出的 PDF，禁用 Fit to page（适应页面），然后测量结果。正确生成的 PDF 无法补偿打印机缩放、纸张变形或不准确的打印设置。

开始之前​

  • 选择 A4 或 Letter 纸张；当前生成器仅使用纵向页面。
  • 根据相机分辨率、视场和工作距离确定靶标的物理尺寸。
  • 确保靶标在所选页边距后的可打印区域内。
  • 使用高对比度、尺寸稳定的材料，并计划将打印件安装在平整、坚硬的表面上。
  • 在外部 jsPDF 库加载期间保持网络连接可用。
  • 确认生成的图案受你计划使用的标定软件及版本支持。

快速流程​

  1. 在 Target type（靶标类型）下选择 Chessboard (OpenCV Standard)（棋盘格——OpenCV 标准）或 Segmented Circular Marker (Agisoft)（分段圆形标记——Agisoft）。
  2. 选择 Paper format（纸张格式）并输入 Margin (mm)（页边距，毫米）。
  3. 输入靶标专用尺寸并检查验证消息。
  4. 选择 Live Preview（实时预览）或更改字段以刷新按比例的 SVG 预览。
  5. 对于棋盘格，确认显示的打印方格数、棋盘尺寸和任何自动适配的方格尺寸。
  6. 选择 Download PDF（下载 PDF）。
  7. 以 100% / 实际尺寸 打印，禁用页面缩放，并在采集标定图像之前用直尺或卡尺验证若干尺寸。

控件与输出​

共享控件​

控件范围或输出
Target type棋盘格或分段圆形标记。
Paper formatA4（210 × 297 mm）或 Letter（215.9 × 279.4 mm）。
Margin5–50 mm。
Live Preview当前页面和靶标的按比例 SVG 表示。
Download PDF本地生成矢量 PDF，文件名包含关键参数和日期。

棋盘格控件​

控件范围或含义
Rows / Columns3–50 个内角，非打印方格数。
Square size请求的 2–100 mm 边长。
Printed grid(内行数 + 1) × (内列数 + 1) 个方格。
Auto-fit如果棋盘放不下，生成器会缩小导出的方格尺寸并报告适配后的值。

分段圆形标记控件​

控件范围或含义
Outer diameter40–250 mm。
Ring width5–60 mm 且不超过外径的一半。
Segment angle20–120°。
Rotation step连续标记之间 0–60°。
Grid rows / columns每个方向 1–10。
Center dot1–10 mm 输入。

预览和导出的 PDF 使用相同的请求标记布局。在打印之前检查 PDF，特别是当大标记或密集网格接近可用单元格尺寸时。

工作原理​

应用以毫米表示所选纸张，并用 SVG 几何构建实时预览。对于棋盘格，它将内角计数转换为打印方格计数，使棋盘居中，并在请求的棋盘超过页边距后的可用页面时按比例缩小方格尺寸。

对于分段圆形标记，它在请求的网格中排列带标签的标记，改变分段宽度和旋转，并在 PDF 中重现该几何。浏览器使用以毫米为单位的 jsPDF 和矢量绘图操作；不涉及图像上传或服务端渲染。

数据、隐私与外部服务​

  • 参数、预览渲染和 PDF 创建均在浏览器中完成。
  • 生成器不会上传靶标设置或生成的文件。
  • jsPDF 从 jsDelivr 加载。如果该外部脚本无法加载，PDF 导出不可用。
  • 生成的文件不会被本站存储；请保留 PDF 并将最终测量尺寸与标定数据集一起记录。

局限性​

  • 当前界面仅提供棋盘格和分段圆形靶标、A4/Letter 纵向页面和 PDF 导出。它不生成 AprilTags、自定义标记、SVG/PNG/DXF 下载、横向页面或批量文件。
  • 棋盘格自动适配会将物理方格尺寸从请求值更改。使用显示的适配值并验证打印件，而非假定输入值被保留。
  • 分段标记尺寸不会自动缩小以适应每个网格单元格；大标记或密集网格可能重叠。
  • "Agisoft" 标识的是预期的标记风格，不保证与每个 Metashape 版本或检测器兼容。在生产任务之前测试识别。
  • 应用验证数值范围和页面适配；它不评估打印机精度、靶标平整度、图像质量、检测器成功率、重投影误差或标定适用性。
  • 不保证固定的尺寸公差或亚像素标定精度。

排障​

问题应检查什么
棋盘格比请求的小阅读自动适配消息；减少行数、列数、方格尺寸或页边距以保留预期比例。
内角计数差一记住打印方格数等于内角数加一（每个方向）。
分段标记重叠减小外径、降低网格密度或增加可用页面区域。
Download PDF 无反应检查网络，重新加载页面，确认 jsPDF 已从 CDN 加载。
打印尺寸错误以实际尺寸打印，禁用所有缩放，检查打印机驱动程序，并测量输出。
标定软件无法检测靶标确认其支持的靶标类型和计数约定，改善对焦和照明，并验证打印的几何。
