MCTP：多模态作物表型数据处理平台

一个桌面平台，以统一界面、交互式调参、批量处理和结构化导出，处理高光谱、LiDAR、RGB 和热红外表型数据。

Liangchao DengPostdoctoral Researcher
Nov 7, 2025·4 min read
Plant PhenotypingImage AnalysisData AnalysisRemote Sensing

概述​

使用步行式平台开展田间表型调查时，每个小区都会产生四类差异很大的数据：高光谱数据立方体、LiDAR 点云、RGB 图像和热红外图像。它们通常各自需要不同的软件、参数约定和导出格式，使多模态性状分析既慢又难以复现。

MCTP（Multi-modal Crop Trait Processing，多模态作物性状处理平台） 把四种模态整合进一个桌面平台，提供统一界面、交互式参数调节、批量处理和结构化导出。平台为黍峰生物的田间步行式表型平台开发，我负责系统优化以及数据处理与分析方法。

功能模块​

高光谱（HyperVis）​

  • 读取 ENVI HDR/SPE 文件对，解析波长元数据；
  • 根据波长自动识别植被指数所需波段；
  • 计算 NDVI，以近红外阈值构建植株掩膜，并用分位数掩膜去除镜面反光；
  • 导出叶片区域平均光谱（CSV）和统计摘要（JSON）；
  • 以标签页展示 RGB 快视图、NDVI、掩膜对比、光谱曲线和统计结果；
  • 对整个目录的 HDR/SPE 文件对批量处理。

LiDAR​

  • 读取 PLY、LAS、LAZ 和文本格式点云；
  • 用 RANSAC 重定地面，再进行体素降采样、裁剪和按高度着色；
  • 用 DBSCAN 分割植株，并在 SegTuner 窗口中交互调参；
  • 计算冠层与植株性状：地面覆盖度、体素占有率、凸包体积，以及高度分位数 H10、H50、H90；
  • 导出裁剪后的点云和 JSON 性状报告。

RGB​

  • 联合 ExG、CIVE、VDI 三种颜色指数并统一阈值，分割植被；
  • 抑制水面和塑料反光，去除标签和边框；
  • 通过自适应形态学运算和骨架增强保留细小植株；
  • 通过分水岭和连通域标记区分单株；
  • 导出叠加图像、小区级 JSON 指标和单株 CSV 表。

热红外​

  • 读取 BMP 图像及其 DDT 温度矩阵，支持翻转和标定；
  • 基于 Otsu 方法和分位数给出建议阈值；
  • 通过滑块调节温度阈值、HSV 范围和形态学参数；
  • 提供叠加图、热图和仅植株三种预览；
  • 导出 PNG、NPY、CSV 和 JSON 结果。

统一设计​

  • 统一界面： 四种模态采用相同布局的控制面板、实时预览和处理日志；
  • 交互调参： 滑块、建议阈值和实时预览，使参数依据数据本身设定；
  • 批量处理： 高光谱和 RGB 数据可批量处理；LiDAR 和热红外数据可在样本间复用已保存的参数；
  • 结构化输出： JSON 和 CSV 格式，可直接用于 R 或 Python 统计分析及性状—产量建模。

推荐使用流程​

  1. 原样归档原始数据和采集元数据；
  2. 打开一个代表性样本，确认文件配对、方向和单位；
  3. 在预览中调节参数，并检查困难样本；
  4. 先处理一小批并与原始数据比对，再扩大规模；
  5. 将阈值、体素大小、聚类参数和软件版本与结果一并保存。

适用范围与后续计划​

四个模块分别处理各自的模态，并在参数和导出上采用统一约定，目前尚未在模态之间进行配准。后续工作包括跨模态配准、跨调查批次的时间序列分析、统一的项目配置模板，以及在服务器端批量处理并生成报告。

如需试用 MCTP 或获取示例数据，请见 CV 页面 中的联系方式。
